# INC-2025-1120: Mobile app users logged out after signing key rotation

## Summary
Mobile banking users were logged out and could not log back in for 70 minutes after a scheduled token signing key rotation.

## Impact
- **Severity:** SEV2
- **Date:** 2025-11-20, 02:00 to 03:10 (Asia/Colombo), 70 minutes
- **Affected services:** Mobile Banking API (`mobile-banking-api`), Identity Service (`identity-service`)
- **Customer impact:** About 41,000 customers affected. No transactions failed.
- **Incident commander:** Nuwan Bandara

## Detection
Login failure alert at 02:04.

## Timeline
| Time | Event |
|---|---|
| 02:00 | Token signing key rotated. |
| 02:04 | Login failures exceed 40%. |
| 02:40 | API nodes found caching the old public key for 24 hours. |
| 03:10 | Cache cleared on all nodes; recovery. |

## Root Cause
Mobile API nodes cached the identity service's public signing key for 24 hours and did not refresh it when validation failed, so tokens signed with the new key were rejected.

## Contributing Factors
- Rotation tested only in a single-node environment.

## Resolution
Key cache cleared; refresh-on-failure added.

|---|---|---|---|
