# INC-2024-1129: Card authorization failures during Black Friday promotion

## Summary
Card authorizations returned decline code 91 (issuer unavailable) for 38 minutes during an evening e-commerce promotion.

## Impact
- **Severity:** SEV2
- **Date:** 2024-11-29, 19:12 to 19:50 (Asia/Colombo), 38 minutes
- **Affected services:** Card Authorization Service (`card-auth-service`), HSM Gateway (`hsm-gateway`)
- **Customer impact:** 9,800 transactions failed or timed out; about 6,100 customers affected.
- **Incident commander:** Amaya de Silva

## Detection
Merchant acquirer called the payments hotline before internal alerting fired. The decline-rate alert threshold of 15% was crossed four minutes later.

## Timeline
| Time | Event |
|---|---|
| 19:12 | Decline rate for card-not-present transactions rises above 10%. |
| 19:16 | Acquirer reports widespread declines by phone. |
| 19:22 | On-call engineer sees HSM gateway requests queuing with wait times above 4 seconds. |
| 19:41 | HSM gateway restarted with temporary pool size of 96. |
| 19:50 | Decline rate back to baseline of 2.1%. |

## Root Cause
The HSM gateway holds a fixed set of 64 sessions to the hardware security modules. Promotion traffic peaked at 2.4 times normal volume, every session was in use, and new PIN and CVV verification requests waited in a queue until the card authorization service timed out after 3 seconds.

## Contributing Factors
- Pool size had not been revisited since the 2022 hardware refresh.
- No alert on HSM session utilization, only on downstream decline rate.
- Load test for the promotion used 1.5 times normal volume.

## Resolution
Pool size raised to 96 by configuration change and gateway restarted node by node.
